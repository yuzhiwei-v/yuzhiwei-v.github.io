# Personal academic homepage of me

[Homepage](https://yuzhiwei-v.github.io/) · [Memos](https://yuzhiwei-v.github.io/memos/) 
## Research

My research studies intelligent interaction that remain effective as environments change. I am particularly interested in closed-loop, long-horizon interaction through:

- grounded perception and action;
- world models for physical interaction planning;
- outcome verification, failure diagnosis, and recovery;
- memory and continual adaptation across tasks, time, and individuals.

## About this repository

This repository contains a self-contained static website for GitHub Pages. It uses plain HTML and CSS, with no framework, package installation, or build step.

```text
.
├── index.html                 # Homepage content
├── styles.css                # Homepage and shared styles
├── memos/

│   └── memos.css             # Memo-page styles
├── assets/
│   ├── images/               # Portrait and project visuals
│   └── videos/               # Optional project demo videos
├── .nojekyll

```
